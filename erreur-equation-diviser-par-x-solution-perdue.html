Maths, première et terminale · erreur fréquente

Pourquoi x² = 8x a deux solutions, 0 et 8, et pas seulement 8 ?

L’erreur consiste à diviser les deux membres par x : x² = 8x devient x = 8. Or diviser par x suppose x non nul, et 0 est justement une solution, car 0² = 8 × 0. La méthode sûre : tout ramener dans un membre, puis factoriser. x² − 8x = 0 s’écrit x(x − 8) = 0, donc x = 0 ou x = 8.

À quoi ressemble cette erreur sur une copie ?

Comment reconnaître cette erreur ?

  • Pour une équation comme x² = 8x, la copie ne donne qu’une solution, et 0 n’y figure pas.
  • Une ligne passe de x² = 8x à x = 8 : les deux membres ont été divisés par x, sans la précision « pour x non nul ».
  • La même perte se produit avec un facteur commun : (x − 2)(x + 3) = 4(x − 2) devient x + 3 = 4, et la solution 2 disparaît.

Quelle méthode pour ne plus la faire ?

  1. Ramener tous les termes dans le même membre, pour obtenir 0 de l’autre côté.
  2. Factoriser, c’est-à-dire transformer la somme en produit, à l’aide du facteur commun.
  3. Appliquer la règle du produit nul : un produit est nul si et seulement si l’un au moins de ses facteurs est nul.
  4. Vérifier chaque solution en la remplaçant dans l’équation de départ.

Trois exercices pour s’entraîner

Exercice 1. Résoudre x² = 7x.

Voir le corrigé

x² − 7x = 0, donc x(x − 7) = 0. Un produit est nul si et seulement si l’un au moins de ses facteurs est nul : x = 0 ou x = 7. Résultat : les solutions sont 0 et 7.

Exercice 2. Résoudre 2x² + 6x = 0.

Voir le corrigé

On factorise par 2x : 2x(x + 3) = 0. Donc 2x = 0 ou x + 3 = 0, soit x = 0 ou x = −3. Résultat : les solutions sont −3 et 0.

Exercice 3. Résoudre (x − 1)(2x + 7) = 3(x − 1).

Voir le corrigé

(x − 1)(2x + 7) − 3(x − 1) = 0. On factorise par (x − 1) : (x − 1)(2x + 7 − 3) = 0, soit (x − 1)(2x + 4) = 0. Donc x = 1 ou x = −2. Résultat : les solutions sont −2 et 1.

Questions fréquentes

A-t-on le droit de diviser par x dans une équation ?

Oui, à condition de traiter à part le cas x = 0. On teste d’abord 0 dans l’équation : s’il la vérifie, c’est une solution à garder. On peut ensuite diviser par x en précisant « pour x non nul ». Factoriser évite cette séparation en deux cas.

Peut-on résoudre x² = 8x avec le discriminant ?

Oui. x² − 8x = 0 a pour coefficients a = 1, b = −8 et c = 0. Le discriminant vaut (−8)² − 4 × 1 × 0 = 64, et les solutions sont (8 − 8)/2 = 0 et (8 + 8)/2 = 8. Quand c = 0, factoriser par x demande moins de calculs.

Comment savoir si mon enfant fait cette erreur ?

Demandez-lui de résoudre x² = 8x. S’il répond seulement 8, il a probablement divisé par x. Un test gratuit en ligne peut aussi repérer cette erreur parmi d’autres erreurs sur les équations, à partir des réponses que votre enfant choisit.
