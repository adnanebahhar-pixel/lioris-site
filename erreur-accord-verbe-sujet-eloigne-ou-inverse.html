Comment accorder le verbe quand le sujet est loin ou placé après ?

L’erreur consiste à accorder le verbe avec le mot placé juste devant lui, alors que ce mot n’est pas le sujet, ou à le laisser au singulier quand le sujet pluriel est placé après lui. Le verbe s’accorde avec son sujet, même si celui-ci est éloigné ou placé après le verbe. Pour le trouver, posez la question « qui est-ce qui ? » devant le verbe, puis remplacez le sujet par « il », « elle », « ils » ou « elles ».

À quoi ressemble cette erreur sur une copie ?

Comment reconnaître cette erreur ?

  • Le verbe est au singulier après un sujet pluriel suivi d’un complément du nom au singulier : « les amies de ma sœur prend ».
  • Le verbe est accordé avec un pronom complément placé devant lui : « il les regardent », « l’entraîneur nous répétons ses conseils ».
  • Le verbe reste au singulier quand le sujet pluriel est placé après lui : « sur la plus haute branche chante deux merles ».

Quelle méthode pour ne plus la faire ?

  1. Repérer le verbe conjugué.
  2. Poser la question « qui est-ce qui ? » ou « qu’est-ce qui ? » devant le verbe : la réponse est le sujet, où qu’il soit placé dans la phrase.
  3. Remplacer le sujet par un pronom : « il », « elle », « ils » ou « elles ». Si le sujet contient « moi », le remplacer par « nous » ; sinon, s’il contient « toi », par « vous ».
  4. Accorder le verbe avec ce pronom, sans tenir compte des mots placés entre le sujet et le verbe.

Trois exercices pour s’entraîner

Exercice 1. Compléter avec le verbe au présent.
Les chiens du voisin ... (aboyer) toute la nuit.
La liste des invités ... (être) sur la table.
Mes parents nous ... (attendre) devant le collège.

Voir le corrigé

aboient : le sujet « les chiens du voisin » se remplace par « ils ». est : le sujet « la liste des invités » se remplace par « elle », car le nom noyau est « liste ». attendent : le sujet est « mes parents » (« ils ») ; « nous » est un complément.

Exercice 2. Compléter avec le verbe au présent.
Sur la plus haute branche ... (chanter) deux merles.
Les conseils que l’entraîneur nous ... (répéter) sont utiles.
Dans ce tiroir se ... (trouver) les clés de la cave.

Voir le corrigé

chantent : qui est-ce qui chante ? « deux merles », sujet placé après le verbe. répète : qui est-ce qui répète ? « l’entraîneur » ; « que » est COD et « nous » est un complément. trouvent : qu’est-ce qui se trouve dans ce tiroir ? « les clés de la cave », sujet placé après le verbe.

Exercice 3. Corriger les erreurs, s’il y en a.
Les élèves que le directeur félicite ce matin semble ravis.
Chacun des joueurs reçoivent une médaille.
Que demandent les habitants du quartier ?
Le bruit des travaux nous empêchent de dormir.

Voir le corrigé

semblent : qui est-ce qui semble ravi ? « les élèves », pluriel (« félicite » est juste : son sujet est « le directeur »). reçoit : le sujet est « chacun », au singulier. Phrase 3 juste : le sujet « les habitants du quartier » est placé après le verbe et il est au pluriel. empêche : le sujet « le bruit des travaux » se remplace par « il » ; « nous » est un complément.

Questions fréquentes

Comment trouver le sujet quand il est placé après le verbe ?

Posez la question « qui est-ce qui ? » ou « qu’est-ce qui ? » devant le verbe. Dans « Sur la plus haute branche chantent deux merles », qui est-ce qui chante ? « Deux merles ». Le sujet peut se trouver après le verbe, par exemple dans une question, dans une proposition relative (« le livre que lisent les élèves ») ou quand la phrase commence par un complément de lieu.

Avec le pronom « qui », avec quoi accorde-t-on le verbe ?

Le pronom relatif « qui » est le sujet du verbe qui le suit. Ce verbe s’accorde avec le nom ou le pronom que « qui » remplace, appelé antécédent : « les enfants qui jouent », « c’est moi qui ai raison », « toi qui connais le chemin ». Attention à « chacun », « tout le monde », « personne » : le verbe est au singulier (« chacun des joueurs reçoit »).

Comment savoir si mon enfant fait cette erreur ?

Dictez-lui « Les amies de ma sœur jouent dehors » et « Il les regarde ». S’il écrit « joue » ou « regardent », il accorde le verbe avec le mot le plus proche. Un test gratuit en ligne peut aussi repérer cette erreur parmi d’autres, à partir des réponses que votre enfant choisit.

Cette erreur est-elle la seule ?
