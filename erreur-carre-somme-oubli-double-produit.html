Maths, collège et seconde · erreur fréquente

Pourquoi (a + b)² n’est pas égal à a² + b² : où est l’erreur ?

L’erreur consiste à mettre chaque terme au carré séparément : (x + 6)² = x² + 36. C’est faux, car un carré est un produit : (x + 6)² = (x + 6)(x + 6). En développant, deux termes de plus apparaissent, 6x et 6x. Le bon résultat est x² + 12x + 36. La règle générale : (a + b)² = a² + 2ab + b².

À quoi ressemble cette erreur sur une copie ?

Comment reconnaître cette erreur ?

  • Le développement d’un carré ne contient que deux termes, alors qu’il en faut trois.
  • Il n’y a aucun terme en x dans le résultat : x² + 9 au lieu de x² + 6x + 9.
  • La même erreur apparaît avec un signe moins : (x − 7)² = x² − 49.

Quelle méthode pour ne plus la faire ?

  1. Réécrire le carré comme un produit : (x + 3)² = (x + 3)(x + 3).
  2. Développer en multipliant chaque terme de la première parenthèse par chaque terme de la seconde : quatre produits.
  3. Regrouper les deux termes du milieu : c’est le double produit.
  4. Tester avec un nombre simple, par exemple x = 1 (pas 0) : si les deux écritures ne donnent pas le même résultat, le développement est faux.

Trois exercices pour s’entraîner

Exercice 1. Développer (x + 5)².

Voir le corrigé

(x + 5)² = x² + 2 × x × 5 + 5² = x² + 10x + 25. Résultat : x² + 10x + 25.

Exercice 2. Développer (5x + 2)².

Voir le corrigé

(5x + 2)² = (5x)² + 2 × 5x × 2 + 2² = 25x² + 20x + 4. Résultat : 25x² + 20x + 4.

Exercice 3. Développer (3x − 4)².

Voir le corrigé

(3x − 4)² = (3x)² − 2 × 3x × 4 + 4² = 9x² − 24x + 16. Résultat : 9x² − 24x + 16.

Questions fréquentes

Comment vérifier un développement sans connaître la formule ?

Remplacez x par un nombre simple dans les deux écritures. Avec x = 1 : (1 + 6)² = 7² = 49. La réponse fausse x² + 36 donne 1 + 36 = 37. La bonne réponse x² + 12x + 36 donne 1 + 12 + 36 = 49. Si les deux nombres diffèrent, le développement est faux. S’ils sont égaux, c’est bon signe, mais ce n’est pas une preuve : évitez x = 0 et testez une deuxième valeur.

Que devient la formule avec un signe moins ?

(a − b)² = a² − 2ab + b². Le double produit prend le signe moins, mais le dernier terme reste positif, car (−b) × (−b) = b². Par exemple, (x − 7)² = x² − 14x + 49. À ne pas confondre avec (a − b)(a + b) = a² − b².

Comment savoir si mon enfant fait cette erreur ?

Demandez-lui de développer (x + 6)². S’il écrit x² + 36, le double produit manque. Un test gratuit en ligne peut aussi repérer cette erreur parmi d’autres erreurs de calcul littéral, à partir des réponses que votre enfant choisit.
